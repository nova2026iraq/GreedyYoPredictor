# Greedy Yo Predictor — نسخة تأسيسية

هذا مشروع Android تأسيسي لتطبيق محلل لعبة المزرعة.

## الموجود حالياً
- شاشة رئيسية عربية.
- طلب إذن النافذة العائمة.
- خدمة نافذة عائمة أولية.
- طلب إذن التقاط الشاشة وخدمة أمامية.
- إعداد بناء APK عبر GitHub Actions.

## ما لم يكتمل بعد
هذه ليست نسخة محلل مكتملة: التقاط إطارات الشاشة وتحويلها إلى صور ثم تشغيل OCR وربط النتائج بسجل الجولات وخوارزمية التوقع ما زالت مراحل تطوير لاحقة. لا تعرض هذه النسخة توقعات حقيقية ولا تتصل بخوادم Hello Yo.

## بناء APK
ارفع محتويات هذا المشروع إلى مستودع GitHub جديد أو فرع مستقل، ثم افتح Actions وشغّل `Build Android APK`. بعد نجاح البناء نزّل Artifact باسم `GreedyYoPredictor-debug`.

## الخصوصية
لا توجد حاجة إلى كلمة مرور Hello Yo. التقاط الشاشة لا يبدأ إلا بعد موافقة المستخدم من نافذة Android الرسمية.
